Scientific agents: state, evidence, and authority

Tool-using AI agents participate in scientific work through information retrieval, code execution, scheduling, instrument interfaces, and experimental records. Their behavior is consequential only in relation to the state they affect and the decisions authorized by the surrounding research organization. My work examines the difference between a model proposing an action and an accountable system admitting that action.

From individual tool calls to execution histories

An agent's tool call is a local event. Some safety and scientific obligations concern sequences of events, resource commitments, or the accumulated state of an experiment. The relevant question is which trusted evidence of prior execution must be retained for the next action to be evaluated correctly.

Scientific memory and invalidation

Agent memory is not exhausted by retrieving prior text. The validity of a remembered observation depends on the environment, operation, and state transition to which it refers. Exact invalidation concerns the conditions under which an earlier record stops supporting a later action.

What Must Agent Memory Preserve? Representation Contracts for Exact Invalidation is listed for the NeurIPS 2026 AgenticOS workshop poster session. The associated essay on experimental state develops the organizational problem. Workshop poster acceptance is separate from main-conference publication.

Evaluation and experimental scope

Agent evaluation needs to separate a model's proposed actions, actual exposure to an enforcement mechanism, enforcement decisions, and resulting world state. A high aggregate benchmark score alone does not establish that each obligation was exercised or that an unsafe transition would have been blocked.

LabTrust-Gym provides a simulated multi-agent laboratory environment for testing coordination and security mechanisms. Its evaluation scope is simulation, with no clinical deployment claim.
